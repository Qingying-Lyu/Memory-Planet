# 记忆星球

本机学习与复习产品，课程材料与题库保存在本地，模型和联网搜索通过星流API调用。

使用范围为本机桌面浏览器，不开发手机端答题、移动端同步或手机端回调链路。

## 打开

双击“打开记忆星球.cmd”。课程库是首页，可新建课程、上传资料，逐份确认已学完。

## 删除课程内容

课程卡片点“删除”，选择：

- 删除整门课程：全部材料、题库及关联学习记录。
- 删除部分材料：勾选材料，同时删除依赖这些材料的题目及记录。
- 仅清空题库：保留课程与材料，不返还已消耗的新题额度。

提交前显示具体删除范围并再次确认。删除仅针对本机产品资料，不操作云端原文档，也不删除引用的外部本地原件。备份中的历史副本不会自动删除。

## 规则与配置

核心规则见“核心规则.md”。AI 环节、Agent 分工、模型选型与实测见“AI与Agent分工及星流模型选型.md”；联网搜索细节见“星流联网搜索说明.md”。data/local-settings.json仅保存配置和密钥文件路径，API Key与WPS SID仍位于用户原来的文件位置。

## 维护

页面设置中可备份、查看维护状态；“恢复记忆星球.cmd”用于离线恢复。backups目录保留可恢复备份，data/models保留离线转写模型。

项目冗余文件清理尚未执行。自动审批阻止了递归目录删除和清理脚本生成，因此当前磁盘仍保留历史课程文件及调试产物。不要将数据库重置视为磁盘文件已删除。
