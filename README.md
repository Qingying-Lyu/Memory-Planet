# 记忆星球

更新日期：2026-10-16。本机学习与复习产品，使用 Windows 桌面浏览器界面，课程、材料、题库和学习记录保存在本机；必要的 AI 推理通过星流调用。不开发手机答题及跨设备同步。

## 使用

双击“打开记忆星球.cmd”启动后台并打开课程库。新建课程、添加资料，解析审核完成后逐份确认已学完。

关闭浏览器只关闭界面，后台任务仍可能运行。双击“关闭记忆星球.cmd”并确认可停止由当前启动器记录的后台；建议先等待解析、出题结束。旧入口启动且未登记的进程不会被此脚本盲目终止。

当前版本仍依赖开发环境和本机路径配置。`data/local-settings.json` 保存模型配置以及 API Key、WPS `wps_sid` 的文件路径，不包含凭据正文。首次配置窗口和最终用户便携版尚未实现。

## 规则与实现状态

[核心规则](核心规则.md)记录用户最新确认的业务规则。代码与规则不一致时属于待修正实现，不能把旧代码写成新规则。已确认首次掌握分乘0.85、85水位减半、共享题目额度和深度复习默认最多30题等要求；这些核心规则已完成本次实现同步；首次配置和最终便携交付改造仍待实施。

## 数据与维护

- 设置中的“存储与维护”可创建手动备份及查看维护状态。
- 自动备份每7天检查，完整内容未变则跳过；新自动备份校验成功后保留最近3份自动备份。手动备份和既有历史备份不自动淘汰。
- “恢复记忆星球.cmd”用于恢复；恢复逻辑要求后台停止，原有数据移入恢复目录，不直接丢弃。当前恢复脚本仍有开发机路径，跨机器恢复前需调整环境。
- 课程删除支持整门课程、部分材料及关联题目、仅清空题库，提交前预览并确认。清空题库不返还历史已用额度；不删除云端资料和项目外原件，备份副本不会随之删除。
