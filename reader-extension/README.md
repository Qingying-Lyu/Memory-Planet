# 页面读取扩展原型

更新日期：2026-10-16。独立Chrome/Edge扩展源码，扩展中的名称仍为“知温页面读取”。不随记忆星球启动自动安装，也不是后台采集Agent。

## 使用与输出

1. 在扩展管理页选择“加载已解压的扩展”，加载本目录。
2. 用户按网站流程登录并打开有权访问的课程页面。
3. 优先选中正文或已显示字幕，点击扩展读取，核对预览后导出JSON。

只申请activeTab和scripting权限。用户点击时读取选中文本，或页面已加载的可见DOM片段；最多150000字符，超出会标注截断，标题列表最多60项。保存标题、来源、时间、方法和覆盖说明，不读取Cookie或密码，不后台上传。

## 当前边界

Canvas、跨域iframe、未加载章节及音轨不能靠本原型完整提取；视频标题、评论和简介不是字幕。不得绕过权限。未完成真实站点兼容验收，不承诺通用WPS/B站支持。

扩展仍提示旧“浏览器读取”接入流程，但当前真实材料页面未发现对应JSON导入入口，因此不能承诺导出后可直接接入当前产品。当前产品已有的WPS链接读取使用后台采集器，与此扩展分开。未来若接入，须校验来源一致、覆盖范围及正文证据。
