# 知温页面读取扩展（本地原型，尚未安装）

这是独立的 Chrome／Edge 浏览器扩展源码，不是已接入 Demo 的自动浏览 Agent。

## 加载与使用

1. 在 Chrome 或 Edge 的扩展管理页开启开发者模式，选择“加载已解压的扩展”，选择本目录。
2. 打开有权访问的 WPS／网课页面，按网站流程登录。
3. 优先选中课程正文或已显示的字幕，点击扩展“读取当前内容”。
4. 核对文本预览，点击“导出已检查的片段”。
5. 回到知温对应课程 → 浏览器读取 → 选择导出的 JSON 文件。

只申请 activeTab 与 scripting 权限，无所有网站常驻权限、无后台上传、无读取 Cookie／密码。用户点击扩展才读取当前页，数据只导出到本地。

## 边界

- 未安装、未在真实 WPS／B 站账号进行兼容验收，不承诺所有页面都可读。
- Canvas、跨域 iframe、受限文档、未加载章节和视频音轨不能通过本原型读取。
- B 站网页标题、评论和简介不是课程字幕。请核验片段，不能直接据此生成完整课程题库。
- 来源 URL 必须与课程里保存的链接一致。短链跳转后，请使用最终课程地址创建来源，避免误关联。
- 不处理付费／权限绕过。若无法读取，可导出文档或提供字幕。

## 后续自动 Agent 接入

授权来源链接 → 使用用户登录会话 → 只在课程相关范围导航 → 逐页／逐章节收集正文与出处 → 标记覆盖范围 → 生成框架草稿 → 人工确认 → 出题审核。

当前提供的是可检验的本地读取结果接口，不是假装抓取成功的加载动画。Codex 当前的 Browser 技能可在用户提供具体链接后协助读取，但不会自动成为独立 Demo 的后台。

实现参考：[Chrome activeTab](https://developer.chrome.com/docs/extensions/develop/concepts/activeTab)、[脚本注入官方教程](https://developer.chrome.com/docs/extensions/get-started/tutorial/scripts-activetab)。
