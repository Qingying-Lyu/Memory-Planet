# 记忆星球界面

更新日期：2026-10-16。由本机FastAPI提供页面，使用根目录“打开记忆星球.cmd”，不要直接双击index.html。

`index.html`、`styles.css`、`app.js`提供界面；`backend-bridge.js`连接真实课程、练习和维护接口；`material-workflow.js`处理材料、版本、知识点及音视频核对。

课程、题库及答题以后台为准。浏览器缓存会话及部分界面状态，不是完整数据备份；后端客户端标记变化会丢弃旧会话。旧原型文件存在不等于当前产品仍采用其规则。

最新业务要求见[核心规则](../核心规则.md)，使用流程见[产品交互与本机运行说明](../产品交互与本机运行说明.md)。关闭网页不会停止后台。
