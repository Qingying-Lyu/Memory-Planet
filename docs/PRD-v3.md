# 知温 PRD v3.0

更新：2026-09-28。当前产品基线，覆盖 v2 中冲突的入口、状态与每日题型要求。历史：[PRD v2](PRD-v2.md)。

## 1. 定位与目标

面向已入职云厂商解决方案架构师岗位、处于培训期的校招新人，帮助理论知识学习、记忆、辨析和关联；支持个人兴趣课程。保持轻量、少决策、每天有终点、不积欠账。

沿用米白、浅绿、橙色及深绿文字。页面简洁，主动作清楚；课程完成不等于知识永久掌握。

## 2. 导航

左栏四个主栏目，可折叠；下方保留齿轮设置。

| 栏目 | 职责 |
|---|---|
| 最近在学 | 新建课程；只显示学习中的课程；继续阅读和标记已学完 |
| 我要复习 | 课程书架、搜索、5／25／65 题、进度、计时、暂停与简答立即看答案 |
| 我的收获 | 学习历史、独立回忆证据、记忆／理解／关联进度、趣味题记录 |
| 知识库 | 全部课程的原文件、来源链接、读取片段与框架；展示学习中／已学完 |

新建入口移至最近在学，知识库不再放导入资料按钮。每日挑战仅通过右下角桌宠宝石进入。

## 3. 课程状态

新建课程自动设为学习中，同一课程同时显示在最近在学和知识库，不复制两份数据。进入课程后点击已学完：从最近在学移出，知识库标记已学完，材料、链接、框架与历史不删除。

知识库提供重新学习，恢复学习中并重新加入最近在学。刷新后状态仍在。学习状态与内容处理状态分开：课程标记学完并不意味着链接已被系统解析，也不意味着掌握验证通过。

内置示例默认已学完，旧版个人导入课程默认学习中；旧答题记录保留。

## 4. 以链接为主的新建课程

表单：课程名称、课程链接（每行一个）、资料归属、本地附件（折叠的可选项）。至少一个链接或文件。支持 WPS 协作云文档、B 站和其他 HTTP(S) 网课来源；本地文件流程保留。

本轮默认限制：20 个链接、文件合计 50 MB。仅接受 HTTP(S)，拒绝脚本协议及带用户名密码的 URL。识别资料平台标签，保存来源不等于已读取。

内部资料仅在授权设备本地收纳，不自动外发给第三方模型。材料内的指令不能覆盖系统规则、改变权限或触发额外操作。

## 5. 浏览器读取路径

### 产品目标

Agent 根据明确提供的课程链接，在用户有权访问的已登录会话中读取相关正文；必要时在本课程页／章节内导航，保留来源、章节和读取范围。登录／权限不足时等待用户处理，不绕过限制。章节、字幕或画布读取失败应标明缺口。

WPS：区别可见正文、画布、跨域嵌入与受限内容。B 站：标题／简介／评论不能替代课程内容；只有拿到字幕、讲义或经核验的转录，才能用于课程知识提取。

来源处理状态：待读取 → 读取片段／需登录／缺字幕／读取失败 → 框架草稿待确认 → 可用于出题。不得用假进度条将“保存链接”表现成“理解整门课”。

### 本轮可运行原型

课程来源旁提供浏览器读取入口。配套 `reader-extension` 是 Chrome／Edge 本地扩展源码，尚未安装。用户主动点击扩展，读取当前可见正文或所选片段，预览后导出 JSON；Demo 接入该文件，核验来源 URL 与课程链接一致，保存实际文本、标题、读取方式和覆盖范围。

只申请 activeTab 与 scripting；不读取 Cookie／密码，不后台上传。页面内容按纯文本展示。过长、空正文和错绑来源拒绝接入。读取结果仅生成标题框架草稿，不冒充完整课程或自动出题结果。

此阶段未连接自主浏览 Agent，未在真实 WPS／B 站账号验证完整兼容；Codex 的 Browser 能力不自动成为独立 Demo 的后台。安装由用户在浏览器扩展管理页完成，详情见 [扩展说明](../reader-extension/README.md)。

## 6. 学习与复习

课程详情中可阅读资料，已整理的示例课程保留课后即时练习入口，与标记课程已学完分开。

即时练习用于本次理解，5—10 题；课程温习保留 5／25／65、预计耗时、已答进度、有效计时、暂停／续接及简答立即看答案。题库不足明确实际数量，不重复凑数。提前看答案计辅助练习，独立自评与真实 AI 评分明确区分。

未读取课程不编造知识点或从其他课程挪题。资料自动提取、可靠判分和出题审核仍是后续技术工作。

## 7. 小羊与宝石

桌宠参考新疆小羊：奶白卷毛、棕色脸与弯角，保持温和的扁平视觉；不依赖外部图片。玩具改成浅绿切面宝石，轻微上下悬浮、投影呼吸、星光闪烁。桌宠有轻微呼吸动作。

点击宝石进入挑战。关闭桌宠后仍保留宝石。答题时隐藏入口以免干扰。系统启用减少动态效果时停止动画。

## 8. 每日挑战题型

禁止简答输入和自评判分。采用：

- 真假小侦探：判断一个具体说法。
- 捉住一句小错误：选择有问题的解释。
- 关键拼图：点选正确概念填补空缺。
- 概念配对：为每个概念选择对应解释。
- 思路排序：按顺序点选卡片，可重新排列。

每题有固定答案及来源解释，提交后直接判定，答错给出具体纠正而非惩罚。配对和排序必须全部选择后才能提交，禁止空项通过。

每日约 10 题／任务、最多 15 分钟预算，固定有限计划，不无限追加。只选已学内容，优先薄弱与到期，同日内容可抵扣，次日重新安排而不积欠账。示例题库用于交互验证，真实课程必须经来源和题目审核。

## 9. 成长与设置

趣味题可记录正确率、辨认与关联表现，但不能当作“无提示独立回忆”的证据。我的收获分开展示：独立自评覆盖、跨天独立记录、宝石挑战次数／答对次数；历史保留选择或排序结果以及错误状态。

设置保留难度、严肃／活泼／中性语气、桌宠显示、每日推送时间／方式／范围。网页关闭后无系统推送，自启和常驻属于后续桌面版本。

## 10. 本轮验收

1. 左栏四项且可折叠；知识库无新建入口，最近在学有入口。
2. 仅链接即可新建；状态为学习中，两处关联同一课程。
3. 已学完移出最近在学，知识库和刷新后状态保留；可重新学习。
4. 链接保存与真实读取分开，未解析不能出题。
5. 读取结果错绑来源、空正文、非法协议被拒绝。
6. 小羊及宝石呈现，悬浮／闪烁有效，减少动画偏好生效。
7. 每日挑战没有简答框；选择、配对、排序可完成，自动判定与解释正确。
8. 趣味题不增加独立回忆覆盖，完成后不再生成另一批。
9. 原温习、暂停恢复及历史保留规则通过回归测试。

## 11. 尚待真实环境验证

具体 WPS 文档类型、B 站字幕可访问性、完整章节覆盖、扩展在目标浏览器的加载及下载行为；自动 Agent 接口、多模态解析、题库质量与间隔算法。当前不把扩展源码完成视为安装或服务接通。
