# 知温：小羊与宝石的养成设计草案

状态：讨论方案，尚未接入 Demo。目标是让用户期待回来，学习任务仍每天清零，不制造补签债务。

## 推荐主循环

完成少量挑战 → 收获宝石 → 装扮小羊、布置草原小屋 → 跨天回忆解锁新景色。学习进步与装扮收集并行，不能用货币购买掌握程度。

| 玩法 | 宝石或学习行为的用途 | 设计边界 |
| --- | --- | --- |
| 小羊衣橱 | 兑换围巾、帽子、铃铛、宝石颜色与互动动作 | 预览后确定兑换，不设抽卡；从桌宠打开，不新增主导航 |
| 草原小屋 | 添置帐篷、地毯、灯串、花圃；自由布置 | 不上线也不枯萎，不要求每天喂养 |
| 小羊旅行 | 完成一段学习后带回明信片、风景与短故事 | 按累计学习推进，无连续签到门槛 |
| 记忆星图 | 不同课程形成星座；跨天再次答对点亮连接 | 展示知识关联；区分客观辨认和独立回忆证据 |
| 小羊成长 | 认真订正、跨天巩固解锁动作或新伙伴 | 不因答错退化；不能靠重复刷同一道题升级 |
| 双人营地 | 好友各自完成小目标，合建营地、送装饰贴纸 | 后续再做；默认不公开公司课程名、资料、答案或成绩 |

## 怎么获得宝石

初版可实验：完成当日挑战给基础奖励；答错后完成订正也给少量奖励；跨天再次巩固另给奖励。每日有收益上限，同题重复练习不重复产出。奖励真实投入，不只奖励满分。具体数量与价格待体验验证，不先承诺最优比例。

精品装饰可要求“累计完成若干次跨天巩固 + 宝石”，避免纯刷数量；用户离开一段时间，既有资产全部保留。

## 复活、商店与好友的选择

建议先做轻量衣橱与家园。商店就是桌宠内的兑换页，显示固定价格、余额和拥有状态，不扩成商城。

每日学习不设失败淘汰：答错免费解释、免费再试，仍可结束今天。不要用宝石复活才能继续学习；这会把错误变成损失。若后续做独立闯关小游戏，可用宝石开启额外趣味关，但不能改变学习成绩或阻止免费订正。

好友放到第二阶段，优先合作而非排行榜：双方共同布置营地、每周互送一张鼓励卡。避免公开成绩竞争、好友强制催学、索取课程正文。好友系统还需要账号、权限与隐私设计，不适合仅为热闹而添加。

## 第一版最小可体验范围

一个宝石余额、六件可预览装扮、一个小屋背景、三个成长动作；从小羊打开衣橱，从悬浮宝石打开每日挑战。先验证用户是否愿意使用装扮，以及挑战的学习价值，再增加旅行和社交。

## 题目质量的下一步

目前示例已加入条件、相近选项与解析，但部分二选配对仍偏容易。正式题库应增加三到四项配对、多条件场景、排查路径和反例辨析；每题绑定已读取材料的具体出处。审核题干信息是否充分、答案是否唯一、干扰项是否合理，避免仅靠“必然、全部”等措辞猜答案。以完成时长、错误选项分布及跨天表现调整难度，不单看满分率。
