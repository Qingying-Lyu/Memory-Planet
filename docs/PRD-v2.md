# 知温 PRD v2.0

更新：2026-09-28。状态：产品与交互基线，技术选型另行设计。参数需试用验证。本版覆盖 [旧版 PRD](PRD-v1.md) 中冲突的设计。

## 1. 定位

面向已入职云厂商解决方案架构师岗位、处于培训期的校招新人，提供资料归档、课程框架、课后练习和持续温习的轻量桌面学习助手。个人兴趣课程可使用同一流程。

目标：理论知识的记忆、理解和关联。解决遗忘快、看懂却说不出、概念混淆、资料分散、不知道复习什么、缺少进步反馈等问题。不包含操作实验、客户模拟、方案设计、课程市场和团队考核。

核心承诺：每次知道做什么、花多久、何时结束；每日重新安排，历史成果保留，不积欠账。

## 2. 信息架构与视觉

| 入口 | 内容 | 主要路径 |
|---|---|---|
| 我要复习（默认首页） | 可搜索课程书架 | 选课程 → 选题量 → 开始答题 |
| 我的收获 | 学习记录、掌握证据、成长变化 | 查看维度进度和历史回答 |
| 知识库 | 每课程一个文件夹，归档原文件和课程框架 | 导入 → 阅读 → 学习完毕 |
| 左下方齿轮 | 设置弹窗 | 难度、语气、桌宠、推送 |
| 右下方悬浮球 | 桌宠的玩具／每日挑战入口 | 查看今日任务 → 开始 |

左栏只有三个主栏目，可收起为图标。折叠后保留文字提示和无障碍名称。桌宠隐藏后保留悬浮球。答题期间隐藏挑战入口，减少干扰。

沿用参考图：米白背景、浅灰绿色侧栏、白卡片、浅绿强调、橙色品牌与挑战入口、深绿黑文字。课程封面可用柔和沙色和灰绿。避免密集仪表盘和重复入口，每屏突出一个主动作。小屏书架自动换列。

## 3. 核心流程

课程创建与资料归属选择 → 多文件导入 → 提取与质量确认 → 简要课程框架 → 阅读学习 → 学习完毕 → 即时练习 → 主动温习／每日挑战 → 反馈纠错与进步记录。

### 3.1 导入与安全

课程包含名称、归属（公司培训／个人学习）、原文件、处理状态、框架及知识点。每个课程文件夹收纳全部材料，可追加并保留版本。

目标支持 PPT、PDF、文档、图片、视频、字幕和文本。导入前明确支持格式、大小限制和处理位置；过程有进度，失败保留原文件并说明原因。允许补字幕或人工补充，不猜测缺失内容。

公司资料单独标识，默认个人可见，不自动共享。企业内容不得未经授权发送到外部服务。材料内的指令只是资料，不能改变系统权限、处理范围或评分规则。原文件可查看或下载，个人知识与公共内容不得自动混合发布。

### 3.2 内容提取与框架

提取正文、标题层级、表格、图示含义和视频时间信息。结果分为正常、局部待确认、失败。每个知识点保留原文片段及页码／段落／时间点。

框架以简洁章节树和少量关键关系呈现，解释“学什么、先后顺序、知识关系”。可展开、编辑、确认、跳回来源。低可信片段不进入评分题。资料更新后标记受影响节点与题目，历史作答保留原题版本。

### 3.3 我要复习

课程书架支持名称检索及全部／公司培训／个人学习筛选。封面展示课程名称、知识点数量和简短学习状态。搜索无结果时提供清楚提示。待提取课程不可直接出题，转到资料详情。

选课后选择 5、25、65 题，默认 5 题，展示预计耗时与当前难度。题库不足时展示实际题数并明确说明，不复制题目凑数。65 题允许分组休息、保存续接。

答题页包含：课程、题型、题干、作答区、进度条、已答／总数、已答时间、暂停／继续、保存返回。暂停隐藏题目并停止计时。离开页面或刷新后恢复到暂停状态，保留未提交答案。

简答题支持立即查看答案。提前查看标为辅助完成；先独立提交再核对才能产生独立表现证据。完成总结包含题量、时间、独立与辅助情况及查看收获入口。

新练习替换未完成会话前明确提示；已经提交的答案不得丢失。

### 3.4 即时练习与课程温习

| 属性 | 即时练习 | 课程温习 |
|---|---|---|
| 触发 | 当前学习范围点击学习完毕，弹出入口，可稍后完成 | 主动选择课程或章节 |
| 数量 | 5—10，受材料容量限制 | 5／25／65 |
| 目的 | 检查理解并即时纠错 | 检查延迟回忆与保持 |
| 题型 | 配对、解释、判断改错、辨析 | 无提示回忆、框架补全、关联、边界、变式辨析 |
| 反馈 | 逐题反馈 | 允许查看单题答案，批次汇总避免相互泄题 |
| 证据 | 即时理解表现 | 跨天独立回答才增加保持证据 |

题目不超出已学范围。同一知识点更换问法，防止记住题面。提示、同日重复和背诵答案不当作长期记忆证明。

### 3.5 每日小挑战

由桌宠玩具悬浮球进入。每日约 10 个任务、总预算 15 分钟以内；依据题型耗时缩减数量，不强凑十题。达到预算提供结束入口，记录成果，剩余任务不成为欠账。

趣味形式：一句话小老师、修正一句话、找异类并解释、补全结构、两个概念牵线、昨日疑问换问法、旧知识重逢。趣味来自回忆方式，不增加无关操作。

选题规则：

- 仅选已学、来源可靠、经过审核的知识。
- 优先到期、薄弱与混淆；同日其他练习可抵扣相同知识点。
- 独立跨天答对越稳定，出现间隔越长；简单重复刷题不增益。
- 辅助完成不增加独立证据；高掌握内容仍在更长间隔后验证。
- 每日只生成有限任务，完成后不自动再来一批；内容不足允许少推。
- 次日重新安排，不显示昨日欠账；保留历史答案和成果。
- 已开始的跨日会话保留草稿，按原计划归属记录，不能在输入中清空。
- 用户可设置参与范围；没有可用任务时明确告知。

每日题额外满足：短、目标明确、有来源、答案边界清楚、有回忆价值。排除重复考点和机械猜题。争议题隔离并反馈，不反复惩罚用户。

### 3.6 我的收获

展示练习次数、学习日期、独立回答知识点、跨天再次独立记录、课程状态与逐题历史。记录题干、答案、课程、日期、模式、辅助状态、评分及来源版本。

首版采用记忆／理解／关联三个等级进度条。显示覆盖与证据，不制造未经验证的掌握百分比。雷达图可扩展；无记录时保持空状态，不填充虚假成绩。

状态：未验证 → 初步独立表现 → 跨天巩固 → 更长间隔保持证据。到期只标待验证，不直接宣布遗忘。投入可被鼓励，但不能代替能力证据。

鼓励须具体：“上次需要提示，这次独立说清”。记录来自自评时必须注明自评，不能宣称 AI 认证。用户可导出历史。

### 3.7 设置

| 项目 | 选项／行为 |
|---|---|
| 难度 | 简单、中等、难；调整认知复杂度，事实标准不变 |
| 语言个性化 | 严肃、活泼、中性；改变陪伴语，不改变评分标准 |
| 桌宠 | 显示／隐藏；扩展形象、大小、动作频率 |
| 每日推送 | 开关、时间、方式（气泡／弹窗）、参与范围 |
| 后续扩展 | 工作日、稍后提醒、桌面自启、备份恢复 |

保存设置后持续生效，可预览提醒。关闭桌宠不移除悬浮球，关闭提醒不影响主动挑战。答题时不推送新任务。

## 4. 质量与记录要求

题目绑定知识目标、来源、答案要点、合理同义表达、核心错误和版本；先确定目标与答案，再出题审核。Agent 之间意见一致不是事实正确的唯一证明。

不确定评分暂缓改变掌握状态。异议入口应保存用户反馈，复核后可撤销错误影响。历史题目与回答可回溯。

核心对象：课程、文件、提取片段、框架节点、知识点、题目版本、练习会话、答案、记忆证据、每日计划、设置。学习记录与原文件备份分别说明。用户内容按纯文本呈现，导入脚本不得执行。

## 5. 必备与扩展

必备：三个主页面、折叠导航、资料归档与框架、即时练习、主动温习、每日有限挑战、进度暂停、答案反馈、学习记录与设置。

扩展：多模态准确提取、可靠自动判分、桌面常驻宠物、系统推送、个性化间隔算法、语音作答、导师审核、交互图谱、多端同步。首版不为扩展堆叠空页面。

## 6. 本轮 Demo 边界

交互原型是本地网页，尚未接入 AI 或桌面外壳。

- 三栏导航、搜索筛选、选题量、题库不足提示、计时暂停、刷新恢复、直接看答案、自评、每日任务、成长记录、资料归档和设置可以实际操作。
- 内置容器基础、云网络入门、仿生学初识三门示例课程，不包含真实公司内部材料。示例视为已学习，便于体验每日挑战。
- 原文件存入当前浏览器，可下载；文本中的 Markdown 标题可生成框架草稿。PPT、PDF、视频不宣称已解析；导入课程不伪造题目。
- 简答采用对照自评。25／65 题按实际题库截断，明确显示数量，不重复凑数。
- 难度目前影响题目维度优先顺序；不是完整难度模型。每日计划是原型规则，不是经过试验验证的记忆算法。
- 提醒仅在页面打开时生效；网页关闭后无系统通知或自启。清除浏览器数据会丢失本地记录，导出学习记录不包含原文件。
- v1 文件留在 demo/legacy；v2 使用独立存储键，不覆盖旧学习数据。

## 7. 验收

1. 默认进入复习书架，左栏仅三个主栏目及设置；折叠后可操作。
2. 名称检索、分类筛选及空结果正确。
3. 5／25／65 可选，实际题库不足有明确说明。
4. 已答进度与时间准确，暂停时间不计入，刷新保留答案。
5. 提前看答案记录为辅助，不增加独立证据。
6. 完成后我的收获更新，无记录不伪造掌握。
7. 每课程收纳原文件与框架；失败／未解析状态明确。
8. 文件可以保存后重新下载；学习完毕触发即时练习。
9. 每日挑战有固定上限，完成后不无限追加，不积欠账。
10. 设置保存并影响语气、桌宠、范围及页面提醒。
11. 弹窗有关闭与键盘焦点控制；小屏页面可阅读操作。
12. 演示能力与待实现能力明确区分。

## 8. 试用验证

以授权的一章培训资料试用两周，观察用户能否无指导开始温习、任务耗时、中断回归、延迟回忆变化、评分异议与提醒关闭情况。根据结果调整题量、间隔和反馈，不以打开次数代替学习效果。
