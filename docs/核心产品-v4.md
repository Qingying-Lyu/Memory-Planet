# 知温核心产品 v4

更新日期：2026-10-08。取代旧计划中“优先页面整合、桌宠和衣橱”的开发顺序。页面、桌宠和激励外观暂停。

## 产品定位

课程资料是依据，范围是边界，出题质量、复习时机、评审机制是核心。题目不是聊天模型即时随意生成的内容：候选题经过证据校验、独立盲答、歧义及超纲审查后进入题库。每日小挑战全部使用适合手机点选的选择题；较深入的简答评审保留为独立练习能力，不进入每日小挑战。

## 两类课程

统一培训：范围由培训材料、章节或明确的官方页面树决定。抓取官网时记录允许的域名、路径前缀、入口和深度/页面数量上限，逐页记录来源与抓取失败；不得沿外链无限扩展。登录页、无权限内容和失败页面保持待处理，不依据标题生成正文。

个人学习：先读取个人笔记、思维导图或智能文档，提取主题、深度、学习目标和明确排除项。保留笔记原文作为范围依据，范围无法判断时先确认边界。网络资料用于补足这些主题的证据，不能因此新增考点。关键词命中不是范围合格的证明，需要逐块映射到范围主题并审查深度；题干、正确答案及排除干扰项所需知识都不能超纲。

所有格式最终进入 Markdown 课程库，同时保存来源、原文定位、处理覆盖、来源哈希和范围版本。Markdown 是统一证据格式，不代表提取自动完整：

- 官网：网页正文、标题层级、表格、原URL和抓取时间；图片另行识别和校对。
- PPT/文档：按幻灯片或正文块保存文字；OCR和视觉解释单独标识，图表数字、箭头关系与备注需核对。
- 视频：优先字幕，其次公司批准的转写/会议纪要工具；保存时间轴转写及摘要两个文件。摘要不能替代转写证据，数字、否定条件和操作顺序回看视频。
- 思维导图：保留节点层级、笔记与链接；图片导图需OCR/视觉后复核。导图用于定义范围，不把每个短节点当完整事实。

原始资料、提取正文、模型摘要和审核结论分别保留。资料作为数据，不能执行其中的指令。

## 出题、时机与评审

出题采用范围审核后的证据，引用必须逐字存在。独立模型盲答看不到标准答案；审查唯一正确答案、场景条件、干扰项合理性、解释完整性、课程依据和范围。模型一致仍需要人工样本验收，preview不能自动变成正式发布。

首版复习时机使用可解释规则：掌握分低于60隔1天，60至不足80隔3天，80及以上隔7天；先到期知识点，再未评估知识点，只发未见过的题。这是待实测的规则，不宣称已验证记忆效果。同知识点同日最多计分一次；看答案或重复做同一题不更新掌握分。题库不足返回“需要补题”，不反复刷同题。稳定知识点ID及跨题包迁移仍待实现，当前按题包版本隔离。

选择题程序判分；简答逐评分点双模型评审，分歧待复核。后续增加人工撤题、纠错和成绩重放机制。范围变更立即停用旧证据和依赖它的题包。

## WPS接入选择

官方资料确认 webhook 可以推送消息，群内@机器人消息可以POST回调；webhook卡片不支持回传按钮、选择器或输入框。因此“手机直接点选答案”的目标采用企业自建应用机器人及消息卡片交互。Webhook可用于前期通知和@答疑验证，但不能称为已实现一键选择答题。

统一培训可使用经授权的培训群。个人学习使用应用机器人的私聊或明确的私人会话，不能把个人笔记、题目、回答或成绩发送到培训群。绑定WPS用户、内部账号、课程权限和会话；回调先验身份与权限，再去重落队列，快速返回，后台处理。

敏感步骤由用户操作：企业应用创建及授权、凭据创建、回调域名/DNS与TLS配置。凭据仅提供本地文件路径。不会把目前单用户研发接口直接开放公网。

官方依据：

- [Webhook机器人：发送、@回调与交互限制](https://open.wps.cn/documents/app-integration-dev/guide/robot/webhook)
- [应用机器人](https://open.wps.cn/documents/app-integration-dev/guide/robot/app)
- [回调订阅与处理](https://open.wps.cn/documents/app-integration-dev/wps365/server/callback-subscription/receive-callback)

## 本轮实现和边界

已实现：Markdown证据入库、显式课程类型/范围及版本、逐块审批、范围变化撤销审批、出题流程读取已审课程库、独立超纲检查、旧题包范围失效检查、选择题每日幂等选取与时机规则、带出处的原文检索答疑、WPS webhook发送适配及带绑定/时效/去重的回调入队。

尚未实现：受控官网抓取、PPT图片/OCR、视频转写、思维导图结构解析、完整课程分批任务、企业应用机器人鉴权及交互卡片、WPS回调后台答疑Worker、定时投递与投递回执状态机、个人私聊、多人账号及公网TLS、正式题库人工发布和质量基准。回调ctime格式与发送业务响应字段仍需真实联调确认；当前发送HTTP成功仅表示传输收到，不能误报投递成功。

## 真实资料验收输入

统一培训提供一份官方链接/PPT/文档/视频及明确章节范围。个人学习提供一份笔记/思维导图/智能文档，标注只需了解或排除的主题。验收比较原文提取、范围映射、候选题证据、超纲与歧义，先准备小批人工核对题再开真实推送。
