# 知温 PRD v3.0

更新：2026-09-28。当前产品基线，覆盖 v2 中冲突的入口、状态与每日题型要求。历史：[PRD v2](PRD-v2.md)。

## 1. 定位与目标

面向已入职云厂商解决方案架构师岗位、处于培训期的校招新人，帮助理论知识学习、记忆、辨析和关联；支持个人兴趣课程。保持轻量、少决策、每天有终点、不积欠账。

沿用米白、浅绿、橙色及深绿文字。页面简洁，主动作清楚；课程完成不等于知识永久掌握。

## 2. 导航

左栏四个主栏目，可折叠；下方保留齿轮设置。

| 栏目 | 职责 |
|---|---|
| 最近在学 | 新建课程；只显示学习中的课程；继续阅读和标记已学完 |
| 我要复习 | 课程书架、搜索、5／25／65 题、进度、计时、暂停与简答立即看答案 |
| 我的收获 | 学习历史、独立回忆证据、记忆／理解／关联进度、趣味题记录 |
| 知识库 | 全部课程的原文件、来源链接、读取片段与框架；展示学习中／已学完 |

新建入口移至最近在学，知识库不再放导入资料按钮。每日挑战仅通过右下角桌宠宝石进入。

## 3. 课程状态

新建课程自动设为学习中，同一课程同时显示在最近在学和知识库，不复制两份数据。进入课程后点击已学完：从最近在学移出，知识库标记已学完，材料、链接、框架与历史不删除。

知识库提供重新学习，恢复学习中并重新加入最近在学。刷新后状态仍在。学习状态与内容处理状态分开：课程标记学完并不意味着链接已被系统解析，也不意味着掌握验证通过。

内置示例默认已学完，旧版个人导入课程默认学习中；旧答题记录保留。

## 4. 以链接为主的新建课程

表单：课程名称、课程链接（每行一个）、资料归属、本地附件（折叠的可选项）。至少一个链接或文件。支持 WPS 协作云文档、B 站和其他 HTTP(S) 网课来源；本地文件流程保留。

本轮默认限制：20 个链接、文件合计 50 MB。仅接受 HTTP(S)，拒绝脚本协议及带用户名密码的 URL。识别资料平台标签，保存来源不等于已读取。

内部资料仅在授权设备本地收纳，不自动外发给第三方模型。材料内的指令不能覆盖系统规则、改变权限或触发额外操作。

## 5. 浏览器读取路径

### 产品目标

Agent 根据明确提供的课程链接，在用户有权访问的已登录会话中读取相关正文；必要时在本课程页／章节内导航，保留来源、章节和读取范围。登录／权限不足时等待用户处理，不绕过限制。章节、字幕或画布读取失败应标明缺口。

WPS：区别可见正文、画布、跨域嵌入与受限内容。B 站：标题／简介／评论不能替代课程内容；只有拿到字幕、讲义或经核验的转录，才能用于课程知识提取。

来源处理状态：待读取 → 读取片段／需登录／缺字幕／读取失败 → 框架草稿待确认 → 可用于出题。不得用假进度条将“保存链接”表现成“理解整门课”。

### 本轮可运行原型

课程来源旁提供浏览器读取入口。配套 `reader-extension` 是 Chrome／Edge 本地扩展源码，尚未安装。用户主动点击扩展，读取当前可见正文或所选片段，预览后导出 JSON；Demo 接入该文件，核验来源 URL 与课程链接一致，保存实际文本、标题、读取方式和覆盖范围。

只申请 activeTab 与 scripting；不读取 Cookie／密码，不后台上传。页面内容按纯文本展示。过长、空正文和错绑来源拒绝接入。读取结果仅生成标题框架草稿，不冒充完整课程或自动出题结果。

此阶段未连接自主浏览 Agent，未在真实 WPS／B 站账号验证完整兼容；Codex 的 Browser 能力不自动成为独立 Demo 的后台。安装由用户在浏览器扩展管理页完成，详情见 [扩展说明](../reader-extension/README.md)。

## 6. 学习与复习

课程详情中可阅读资料，已整理的示例课程保留课后即时练习入口，与标记课程已学完分开。

即时练习用于本次理解，5—10 题；课程温习保留 5／25／65、预计耗时、已答进度、有效计时、暂停／续接及简答立即看答案。题库不足明确实际数量，不重复凑数。提前看答案计辅助练习，独立自评与真实 AI 评分明确区分。

未读取课程不编造知识点或从其他课程挪题。资料自动提取、可靠判分和出题审核仍是后续技术工作。

## 7. 小羊与宝石

桌宠参考新疆小羊：奶白卷毛、棕色脸与弯角，保持温和的扁平视觉；不依赖外部图片。玩具改成浅绿切面宝石，轻微上下悬浮、投影呼吸、星光闪烁。桌宠有轻微呼吸动作。

点击宝石进入挑战。关闭桌宠后仍保留宝石。答题时隐藏入口以免干扰。系统启用减少动态效果时停止动画。

## 8. 每日挑战题型

禁止简答输入和自评判分。采用：

- 真假小侦探：判断一个具体说法。
- 捉住一句小错误：选择有问题的解释。
- 关键拼图：点选正确概念填补空缺。
- 概念配对：为每个概念选择对应解释。
- 思路排序：按顺序点选卡片，可重新排列。

每题有固定答案及来源解释，提交后直接判定，答错给出具体纠正而非惩罚。配对和排序必须全部选择后才能提交，禁止空项通过。

每日约 10 题／任务、最多 15 分钟预算，固定有限计划，不无限追加。只选已学内容，优先薄弱与到期，同日内容可抵扣，次日重新安排而不积欠账。示例题库用于交互验证，真实课程必须经来源和题目审核。

## 9. 成长与设置

趣味题可记录正确率、辨认与关联表现，但不能当作“无提示独立回忆”的证据。我的收获分开展示：独立自评覆盖、跨天独立记录、宝石挑战次数／答对次数；历史保留选择或排序结果以及错误状态。

设置保留难度、严肃／活泼／中性语气、桌宠显示、每日推送时间／方式／范围。网页关闭后无系统推送，自启和常驻属于后续桌面版本。

## 10. 本轮验收

1. 左栏四项且可折叠；知识库无新建入口，最近在学有入口。
2. 仅链接即可新建；状态为学习中，两处关联同一课程。
3. 已学完移出最近在学，知识库和刷新后状态保留；可重新学习。
4. 链接保存与真实读取分开，未解析不能出题。
5. 读取结果错绑来源、空正文、非法协议被拒绝。
6. 小羊及宝石呈现，悬浮／闪烁有效，减少动画偏好生效。
7. 每日挑战没有简答框；选择、配对、排序可完成，自动判定与解释正确。
8. 趣味题不增加独立回忆覆盖，完成后不再生成另一批。
9. 原温习、暂停恢复及历史保留规则通过回归测试。

## 衣橱与旅行增量估算（方案估计，不是实测）

基线：已有账号/本地持久化、桌宠、每日挑战、课程导入与评估的可用产品；不计训练模型、视频识别等独立基础设施。一个人日为约一天有效实现与验证工作。

- 轻量衣橱：6至10件静态装扮、固定价格、余额及穿戴保存，约3至5人日。
- 轻量旅行：3至5条固定路线、按累计学习进度解锁明信片，无实时地图或额外AI生成，约4至7人日。
- 两者共享奖励流水、防重复领取、迁移和回归约2至4人日；合计约9至16人日，含简单素材整理，不含专业美术外包。
- 若核心产品投入60至80人日，增量约11%至27%；若仅20人日原型，则是45%至80%。百分比高度取决于分母，不应概括成一个固定数字。
- 运行资源：静态配置和事件触发，无后台常驻循环时，日常CPU/内存影响预计小，但无性能测量不能承诺百分比。资源体积先设新增压缩图片1至3MB预算，按需加载；假如原包10MB则增加10%至30%，原包1MB则增加100%至300%。这些是预算示例不是当前包测量结果。
- AI调用：固定故事、固定装扮与确定性解锁可做到新增0次；如果动态生成旅行故事或图片，成本需另计。
- 界面：从小羊打开衣橱/旅行，不新增主导航；点击宝石仍直达挑战。每次学习不强制弹奖励动画。

建议先上衣橱，验证使用率与主任务完成率，再做旅行。暂停使用不扣资产，不设饥饿、补签债务或付费复活。

## 评分规则 v2（用户确认，2026-09-29）

本节替代 v1；本次仅更新需求，Demo 代码和历史成绩尚未迁移。

### 本次题目得分与知识点掌握分

- 本次得分 Q 范围0—100，知识点累计掌握分 M 范围0—100。无有效作答显示未评估。
- 第一次有效测评：M₁ = 0.8 × Q₁，最高80分。
- 第 n 次有效测评（n≥2）：Mₙ = Mₙ₋₁ + αₙ × (Qₙ − Mₙ₋₁)。
- αₙ = 0.5 / √n × k；更新前 M < 80 时 k=1，M≥80时 k=0.5。
- 本次表现高于历史掌握分则涨，低于则降。测评次数越多权重越低；80分以上额外减半；连续满分无限逼近100。
- 内部保留计算精度，界面一位小数，内部不足100不得显示100，可向下截断一位。记录规则版本、原分、本次Q、n、权重、新分与时间，支持复算。
- 连续满分时，第1/2/3/5/10/15次约为80/83.5/85.9/89.0/93.1/95.2，仅作为公式演示。权重为产品设定，需后续验证与校准。

### 简答题评分

题目发布前明确评分点、权重、部分得分条件与关键错误规则，权重合计100。示例：概念40、机制关系35、适用条件25。AI逐项判断完整/部分/未答到，分别取该项权重的100%/50%/0%，引用回答原文解释判断；程序加总Q，不接受模型直接输出整体印象分。同义表达可得分，关键词出现但语义相反不得分。关键错误规则必须提前定义，不临时追加扣分。评分失败或有争议时标记待评审，不以0分替代；允许复核，避免同一提交重复累计。每日趣味挑战仍为客观题，简答评分用于课程复习与即时练习。

### 有效测评与复习频率

首次提交、未提前看答案或提示的回答可计分。同知识点同一天最多更新一次，以当天第一次有效测评为准；订正保留但不重复涨分。尽量采用等价变式题。跨端使用统一知识点ID、测评事件ID与业务日期去重。

复测间隔：低于60为1天；60至不足80为3天；80至不足90为7天；90至不足95为14天；95及以上为30天（已掌握，低频维护）。按未舍入分数判定区间。到期只是抽题候选，不形成欠账；答错后依据新分数安排。课程内薄弱知识点仍单独推送，不因课程平均较高被忽略。不凭空按离线时间扣分。

课程按提前确定且版本化的知识点权重汇总。完整覆盖前仅展示“已测部分得分”与覆盖率，不标整门课程已掌握。未测不当作答错，也不能被悄悄忽略后宣称整课掌握。能力网不把知识题分数直接等同岗位胜任能力。

历史迁移：保留旧原始记录与旧规则版本；不把旧自评转换为AI评分；缺少首答/辅助信息的记录不自动纳入新分数。迁移方案与确认过程另行实现。

## 手机每日挑战伴侣（可行性方案，尚未实施）

默认讨论微信小程序。仅提供今日挑战、答题进度、结果/待评审状态、提醒偏好和账号绑定；课程导入、材料解析、出题和AI评审由电脑端承担。

推荐：电脑预生成已审核题包 → 轻量同步服务存储与分发 → 手机答题 → 同步服务保存作答 → 电脑上线评审并回传结果。服务承担身份校验、权限、消息调度、去重与队列，不承担模型推理。电脑关机时已同步题包仍可答，严格电脑评审模式显示待评审；电脑恢复后处理。若允许把确定性客观判题交给同步服务，可立即反馈，须与严格电脑评审模式区分。

每日任务两端共享，重复提交不重复计分或发宝石。提前同步可覆盖未来若干天，题包不足如实提示，不编造新题。提醒不等于手机常驻定时器，微信订阅消息的授权、模板与主体资格需核实，不承诺一次授权后永久每日推送。

公司培训题干及解析也可能含内部信息，默认不向个人云同步；仅允许授权范围内的课程进入手机题包，使用企业批准存储或保留电脑端学习。

工作量初估：当前纯本地Demo基础上，小程序页面4—6人日，同步/身份/去重5—8人日，电脑上传与评审队列3—5人日，提醒和跨端验证3—5人日，合计15—24人日；不含等待平台审核及企业部署审批。若已有可复用同步后台，约7—12人日。此为范围估算，不是排期承诺。
